Referensi Operator Aritmatika JS

Pelajari sintaks operator aritmatika bawaan ECMAScript dan coba langsung pada kalkulator.

Simbol Nama Operator Sintaks JavaScript Deskripsi Operasi Aksi Cepat
+ Penjumlahan (Addition) let c = a + b; Menjumlahkan nilai numerik atau menggabungkan string.
− Pengurangan (Subtraction) let c = a - b; Mengurangi angka pertama dengan angka kedua.
× Perkalian (Multiplication) let c = a * b; Mengalikan dua nilai numerik dengan presisi floating point.
÷ Pembagian (Division) let c = a / b; Membagi angka pertama dengan angka kedua.
% Modulus (Remainder) let c = a % b; Menghasilkan sisa hasil bagi dari bilangan bulat.
** Eksponensial (Exponentiation) let c = a ** b; Memangkatkan angka pertama dengan angka kedua (ES2016).
